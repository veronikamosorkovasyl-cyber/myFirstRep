# myFirstProjret

My Favorite Anime: JoJo's Bizarre Adventure - Diamond is Unbreakable

A responsive, feature-rich web page dedicated to **JoJo's Bizarre Adventure: Part 4 (Diamond is Unbreakable)**. This project highlights key characters, plot details, promotional imagery, video content, and personal reasons for loving the series.

---

## 🌟 Features

* **Interactive Navigation & External Links:** Quick links to the official JoJo Wiki, gallery, character categories, plot summaries, and streaming platforms.
* **Dynamic Theme Toggle:** Built-in light/dark theme switching functionality managed via custom JavaScript (`script.js`).
* **Image Carousels:** Showcases official anime promo posters, key visuals, Blu-ray covers, and themed event promotional art.
* **Character Profiles:** Detailed breakdowns of main characters and allies from Part 4:
  * Josuke Higashikata (with *Crazy Diamond*)
  * Koichi Hirose (with *Echoes*)
  * Okuyasu Nijimura (with *The Hand*)
  * Jotaro Kujo (with *Star Platinum*)
  * Rohan Kishibe (with *Heaven's Door*)
* **Embedded Video Trailer:** Directly embedded official trailer for *Diamond is Unbreakable*.
* **Series Information:** Quick-reference facts including Japanese title, romaji, episode count, broadcast dates, producers, and animation studio (`David Production`).
* **Personal Review Section:** Outlines unique art styles, narrative depth, Stand mechanics, and community impact.
